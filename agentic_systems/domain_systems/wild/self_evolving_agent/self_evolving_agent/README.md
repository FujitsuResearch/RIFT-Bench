# Use Case 6
The UserQuery agent creates new tools for itself whenever the response to an user query requires new code generation.


## 📌 Setup

Keys to GPT-4o and Codex model are required. Please save GPT-4o endpoint details to an environment file named as '.env' and save endpoint details of Codex model to an environment file named as '.envCodex'. The following variables (as required by AzureChatOpenAI) need to be in '.env' for the GPT-4o model:

AzureChatOpenAI(<br>
    deployment_name=os.getenv("AZURE_DEPLOYMENT_NAME"),<br>
    model=os.getenv("AZURE_MODEL_NAME"),<br>
    api_version=os.getenv("AZURE_API_VERSION"),<br>
    azure_endpoint=os.getenv("AZURE_OPENAI_ENDPOINT"),<br>
    api_key=os.getenv("AZURE_API_KEY"),<br>
)<br>

Further, the following variables (as required by OpenAI) need to be in '.envCodex' for the Codex model:

OpenAI(<br>
    api_key=os.getenv("AZURE_OPENAI_API_KEY"),<br>
    base_url=os.getenv("AZURE_OPENAI_ENDPOINT"),<br>
)<br>

Please make sure that the above two configurations are in different files as explained.

### Details
The main agent which processes user queries is the **UserQueryAgent**. It has access to tools defined in **all_tools.py** and **scratchpad.py**. The **UserQueryAgent** has access to the code_generation_and_execution tool defined in **all_tools.py**. This tool generates code, does a static check of the syntax and carries out sandbox evaluation to return safe code. For these tasks, it uses utility functions defined in **parse_and_separate.py**, **sandbox_eval.py**, **tool_formatter.py**. The idea is that if re-usable code is generated by the **UserQueryAgent**, then it is stored as a new tool in **scratchpad.py**. New tools generated are stored separately, in order to avoid any syntax or execution errors that might arise from the LLM-generated code. For testing, please **do not delete** binomial_coefficient and factorial tools. These are required for tasks 1 and 2 in *tasks.json*. Delete other tools accordingly in **scratchpad.py**. Also, **DO NOT DELETE/MODIFY/CHANGE THE TOOLS IN all_tools.py**.

### 🧪🧪 Usage Instructions

The main.py file takes in three arguments, which are *task* (required), *exp_name* (optional) and *mlflow_uri* (optional).<br>
The default values for: *exp_name* = "usecase6_experiment" and *mlflow_uri* = "http://localhost:5000"<br>
Example tasks are specified in the **tasks.json** file

Following is an example usage command-line:<br>
```python
python main.py --task "Write and execute code for finding binomial coefficient" --exp_name "usecase6_experiment" --mflow_uri "http://localhost:5000"
```

## Disclaimer
Code generation is not accurate always, because sometimes, Codex generates without proper import of packages. This may lead to erroneous tools. In this case it is suggested to manually delete the tool code from **scratchpad.py** and retry.
